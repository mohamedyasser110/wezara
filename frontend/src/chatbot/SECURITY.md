## 1) نموذج التهديد

| # | التهديد | السطح | الأثر |
|---|---------|-------|-------|
| T1 | حقن HTML/JS في سؤال المستخدم يظهر في الرد | `ChatWidget` يعرض نص الرد | XSS في المتصفح |
| T2 | استعلام خارج القائمة (SQL/NoSQL خام، `DROP`، قراءة جداول أخرى) | `runSafeQuery` | تسرّب/تخريب بيانات |
| T3 | ضيف يطلب بيانات خاصة (`myApps`: طلباتي) | `answer(..., {user:null})` | تسرّب بيانات مستخدمين آخرين |
| T4 | هلوسة: إجابة مؤكدة من خارج المعرفة (أكواد/حالات طلب مخترعة) | عتبة الثقة | قرار إداري خاطئ |
| T5 | إدخال ضخم (20k+ حرف) أو رد بلا سقف | `answer` | تجميد UI / DoS |
| T6 | تسرّب أسرار (توكن، كلمة مرور، سلسلة اتصال DB، رقم قومي) في النصوص | المعرفة/الردود | اختراق حسابات |
| T7 | تجاوز الدخول عبر انتحال هوية (تزوير `x-user-id` التجريبي) | طبقة الـauth | وصول غير مصرّح (T3) |

## 2) الضوابط (مغطّاة باختبارات في `engine.test.ts`)

| الضابط | القيمة | الحالة المغطّية |
|--------|--------|------------------|
| C1 — لا HTML في النص أبداً: الردود `text/plain` + هروب (`escapeHtml`) لأي إدخال مُعاد عرضه، والـWidget يعرض كنص لا `dangerouslySetInnerHTML` | invariant دائم | حقن `<script>` + اختبار الهروب |
| C2 — allowlist صارمة: `runSafeQuery` تقبل فقط `getInitiatives / getInitiativeDetails / getMyApplications / getFaqAnswer / listShowcase`، وغيرها → خطأ `QUERY_NOT_ALLOWED` | 5 أسماء فقط | مرفوض → خطأ / مسموح يعمل |
| C3 — بوابة دخول: نيّة `myApps` بلا `user/userId` → `LOGIN_REQUIRED` + توجيه لصفحة الدخول، ولا تُرجع أي صفوف | `requiresAuth` | ضيف → دخول / مسجّل → بيانات |
| C4 — عتبة ثقة: `confidence < 0.5` (أو لا تطابق) → رد توضيحي ثابت، ممنوع اختراع مبادرات/حالات/أكواد | 0.5 | هراء → توضيح / فارغ → توضيح |
| C5 — سقوف: إدخال ≤ 500 حرف (يُقلَّم أولاً)، رد ≤ 1000 حرف (`MAX_ANSWER_LENGTH`) | 500 / 1000 | كل الردود ≤ السقف + إدخال 20k |
| C6 — تقليم البيانات: لا كلمات سر/توكنات/سلاسل اتصال/أرقام قومية (14 رقماً) في أي رد أو مقترح؛ فحص آلي بـregex في الاختبار | صفر تسرّب | فحص الأسرار |
| C7 — تطبيع عربي قبل المطابقة: `أإآ→ا، ة→ه، ى→ي، ؤ→و، ئ→ي` + إزالة التشكيل + أرقام عربية→لاتينية + تقليم مسافات | — | 5 حالات تطبيع |
| C8 — `SUGGESTED_STARTERS` ≥ 3 مقترحات، ≤ 80 حرفاً، بلا HTML — لتقليل الأسئلة الحرّة المفتوحة | 3+ / 80 | اختبار المقترحات |

ملاحظةauth (خلفية حقيقية، `backend/src/middleware/auth.ts`): المسار الإنتاجي JWT عبر
`Authorization: Bearer`، و`x-user-id` تجريبي للتطوير فقط (`allowDemoAuth`) — لذلك يجب
على أي جسر خلفي للشات بوت تمرير JWT لا المعرّف التجريبي في الإنتاج (يغلق T7).

## 3) ممنوع (على وكلاء المحرك/الاستعلامات/الواجهة)

1. **ممنوع** وصول مباشر لأي DB من `frontend/src/chatbot/` — كل البيانات عبر
   `runSafeQuery` بالـallowlist فقط، ولا SQL/NoSQL خام ولا سلاسل اتصال.
2. **ممنوع** تخزين/طباعة أسرار (`VITE_*` سرّي، توكنات، كلمات مرور) في كود الفرونت
   أو `knowledge/*.json` — الفرونت علني بالكامل.
3. **ممنوع** عرض الرد بـ`dangerouslySetInnerHTML` أو حقن HTML من المعرفة/المستخدم.
4. **ممنوع** إرجاع بيانات مستخدم آخر: أي استعلام خاص يُقيَّد بـ`userId` الجلسة،
   والضيف يُحجب دائماً (`LOGIN_REQUIRED`).
5. **ممنوع** الإجابة خارج المعرفة بثقة: أي سؤال تحت العتبة → الرد التوضيحي الثابت،
   لا تأليف أسماء مبادرات أو حالات طلب أو روابط.
6. **ممنوع** مدخلات/مخرجات بلا سقف: التزم C5 في كل مسار جديد (صور/ملفات/تواريخ).
7. **ممنوع** تعديل `engine.test.ts` من وكلاء آخرين — هو عقد القبول؛ غيّر السلوك
   بإصلاح implementation لا بإضعاف الاختبار.
