# قاعدة معرفة الشات بوت العربي — knowledge/

مجلد محجوز لوكيل المعرفة فقط. البوت يجيب حصريا من هذه الملفات + الـviews الحقيقية للموقع. ممنوع اختراع صفحات أو أزرار غير موجودة.

## الملفات (4 فقط)

| الملف | المحتوى |
|---|---|
| `faqs.ar.json` | مصفوفة أسئلة: `{id, q[], a, links[{labelAr, view, initiativeId?}], keywords[]}` — كل إجابة عملية بخطوات وتشير لصفحة/زر موجود فعلا |
| `site-map.json` | خريطة الصفحات: `{view, labelAr, labelEn, descAr, auth, howAr}` — المرجع الوحيد للتنقل (`home`, `initiatives`, `initiative-detail`, `my-initiatives`, `factory-portal`, `compare`, `login`) |
| `keywords.json` | خريطة نية → مرادفات عربية (تشمل عامية: عايز، ازاي، فين، أقدم، ورق، حساب) |
| `README.md` | هذا الملف |

## الصفحات الحقيقية (المصدر: `App.tsx` + `HeaderNavbar.tsx` + `state.ts`)

- العامة (بدون دخول): `home` (الرئيسية)، `initiatives` (المبادرات)، `initiative-detail` (صفحة المبادرة: المزايا / الأسئلة الشائعة / الجهات الشريكة / المستندات المطلوبة / فحص الأهلية / التقديم الآن)، `compare` (المقارنة — مبادرتان على الأقل)، `login` (الدخول + تسجيل منشأة جديدة + إعادة التفعيل).
- للمسجلين فقط: `my-initiatives` (مبادراتي — محجوبة عن الزائر)، `factory-portal` (بوابة المصانع — الملف الموحد + ملف PDF).
- أزرار حقيقية: المبادرات / مبادراتي / المقارنة / المصانع / تسجيل الدخول / تغيير كلمة المرور / تسجيل الخروج / البحث (Ctrl+K) / زر اللغة (English/العربية).
- مبادرات حقيقية (seed): `init-solar-2026` (شمس الصناعة — نشطة)، `init-solar-1` (الطاقة الشمسية للمصانع — نشطة)، `init-modernization-2026` (تحديث خطوط الإنتاج — نشطة)، `init-import-sub-2026` (تعميق المكون المحلي — قريبا).
- جهات حقيقية: وزارة الصناعة، IDA، IMC، البنك الأهلي، بنك مصر، القابضة لكهرباء مصر، مقدمو الطاقة.
- حالات الطلب الحقيقية: مسودة / مقدم جديد / قيد المراجعة / مطلوب مستندات / معتمد / مرفوض / قيد التنفيذ / مكتمل / ملغي.

## كيف تُضاف أسئلة جديدة

1. أضف كائنا جديدا لآخر مصفوفة `faqs.ar.json` بحقول: `id` (إنجليزي فريد kebab-case)، `q` (3-5 صيغ عربية تشمل صيغة عامية واحدة على الأقل)، `a` (عربية قصيرة بخطوات مرقمة)، `links` (صفحة/زر موجود في site-map)، `keywords`.
2. إن أضفت نية جديدة أضف مرادفاتها في `keywords.json`.
3. لا تضف `view` غير موجود في `site-map.json`. لا تضف `initiativeId` غير موجود في seed-data.
4. تحقق: JSON صالح (بدون تعليقات)، UTF-8، ثم `node -e "JSON.parse(require('fs').readFileSync('<file>','utf8'))"` لكل ملف.
